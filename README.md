# Portfolio Optimization (NIFTY 50)

A multi-approach exploration of portfolio optimization using:
- Classical Finance Models
- Machine Learning Enhancements
- Quantum-Inspired QUBO Formulation

## Structure

- 0_project_framing → Problem + methodology
- data → Raw + processed datasets
- 1_classical_baseline → Mean-variance baseline
- 2_ml_enhancements → ML-based improvements
- 3_qubo_formulation → Quantum-inspired optimization
- 4_benchmarking → Cross-method comparison
- 6_showcase → Key insights + demo
